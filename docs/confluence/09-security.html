Fixed during the review: unlimited sign-ups, zip-bomb spreadsheet, CSV tab trick, PHP version shown, blocked web-cron address.

Accepted lower risks: "Open kiosk without login" (off by default, warned), an admin can reset another admin's password (not the owner's), portal names can be checked for existence, inline scripts allowed by the content policy.

Your security habits

  • Two copies of app.key and config.php in the password manager
  • Recovery codes saved; create new ones after using any
  • 2-Step Verification on Google, Microsoft 365, Hostinger, Namecheap, Stripe, GitHub, Atlassian, Claude
  • Calendar reminder for the Microsoft Graph client secret expiry
  • Never paste a key or password into chat, email, Confluence or GitHub
  • Check that the Microsoft app is limited to contact@ and reports@ (Test-ApplicationAccessPolicy, page 4)
