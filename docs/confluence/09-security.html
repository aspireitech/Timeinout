Your security habits

  • Two copies of app.key and config.php in the password manager
  • Recovery codes saved; create new ones after using any
  • 2-Step Verification on Google, Microsoft 365, Hostinger, Namecheap, Stripe, GitHub, Atlassian, Claude
  • Calendar reminder for the Microsoft Graph client secret expiry
  • Never paste a key or password into chat, email, Confluence or GitHub
