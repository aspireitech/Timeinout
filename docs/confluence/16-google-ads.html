A small, measured Google Ads test for ClockInOut, plus the four demo videos for YouTube. Goal: find out, for about $350, whether people who search for an app like ours start a free trial. Written for someone who has never run Google Ads.

Rules for the test: $12 a day for 4 weeks (about $350). Search ads only. United States only. Stop early if $200 brings no trial, demo or checklist sign-up. Keep going and raise the budget only when a trial costs less than about $60.

1. Before you start (10 minutes, once)

  1. Upload the latest zip (it adds Google Ads conversion tracking and the free checklist).
  2. Go to ads.google.com, sign in with the Google account that runs the Google Business Profile, and create an account. When Google offers a "Smart campaign" or asks for a goal, click Switch to Expert Mode (small link at the bottom), then Create an account without a campaign. Smart campaigns spend money on searches you cannot control.
  3. Billing: country United States, time zone America/Denver, currency USD, add a card. New accounts often get an offer like "spend $500, get $500 credit": accept it if shown.
  4. Tools → Linked accounts → Google Analytics (GA4): link it if you use GA4 (optional).

2. Conversion tracking (so Google knows what a success is)

  1. Google Ads → Goals → Conversions → Summary → + New conversion action → Website. Enter clockinoutapp.com → Scan → Add a conversion action manually.
  2. Create Sign-up: category Sign-up, value: use the same value, $40; Count: One; click-through window 30 days. Save.
  3. Create Lead: category Submit lead form, value $10; Count: One. Save.
  4. For each one choose Use Google tag → Install the tag yourself. In the "event snippet" find send_to: 'AW-123456789/AbCdEfGh'. The part before the slash is the Conversion ID (same for both); the part after is the label.
  5. Open clockinoutapp.com/super → Settings → Google Ads conversion tracking, paste the Conversion ID, the Sign-up label and the Lead label → Save settings.

    You do not paste any code into the website: ClockInOut adds the tag itself, only on the public website, and fires Sign-up on the welcome page after a trial starts and Lead after a demo request, a call-back request or a checklist sign-up.
  6. Check: start a test sign-up on your phone, then in Google Ads → Conversions the status changes from "Inactive" to "Recording conversions" within a few hours. Delete the test portal afterwards in /super → Subscribers.

3. Create the campaign

  1. Campaigns → + New campaign → Create a campaign without a goal's guidance → Search. Results: tick Website visits, enter https://clockinoutapp.com. Name: Search – US – Test.
  2. Bidding: Clicks → tick Set a maximum cost per click bid limit → $3.00. (Switch to "Conversions" only after the account has 15 or more conversions in 30 days.)
  3. Networks: untick Search Partners and untick Display Network.
  4. Locations: United States. Open Location options → choose Presence: people in or regularly in your included locations.
  5. Languages: English. Audience segments: skip. Broad match: off.
  6. More settings → Ad schedule: Monday–Friday, 7:00 AM – 7:00 PM. Campaign URL options → Final URL suffix: src=gads (so the Sales dashboard shows these visits and sign-ups under the source gads).
  7. Budget: $12.00 per day.
  8. Create the four ad groups below. In each one, type the keywords exactly as shown: "quotes" = phrase match, [brackets] = exact match. Put one keyword per line.

8. After 4 weeks: decide

  • Trial costs under $60 (spend ÷ trials): raise the budget to $25/day, keep the best ad group, test a second ad.
  • Clicks but no trials: the page or the offer is the problem, not the ads: look at the landing page with fresh eyes, test the checklist as the main ask.
  • Few clicks: raise the max CPC to $4 or add more keywords from the search terms report.
  • Nothing after $200: pause, and put the money into Capterra/GetApp listings or a local directory instead.
