What the customer sees

When the trial ends, the admin portal opens only Billing (and Help) until a plan is paid. The kiosk keeps working 7 more days, then pauses.

Stripe setup (step by step)

  1. Product: Stripe → Product catalog → Add product "ClockInOut", tax code txcd_10103001 (SaaS, business use).
  2. 6 prices on that product, all Recurring: monthly $39, $79, $149 and yearly $390, $790, $1,490.
  3. Copy each price ID (starts with price_, not prod_) into /super → Settings → Stripe: monthly and yearly field for each plan.
  4. Secret key: Developers → API keys → Secret key (sk_live_…) → paste in /super → Settings. Never the publishable key.
  5. Webhook: Developers → Webhooks → Add destination → "Your account" → snapshot payload → URL https://clockinoutapp.com/webhooks/stripe → events checkout.session.completed, customer.subscription.updated, customer.subscription.deleted, invoice.paid, invoice.payment_failed → copy the signing secret (whsec_…) into /super → Settings.
  6. Customer portal: Stripe → Settings → Billing → Customer portal → turn on (lets customers change card or cancel).
  7. Sales tax (optional): turn on Stripe Tax and add your Utah registration, then tick "Collect sales tax with Stripe Tax" in /super → Settings. Utah taxes SaaS; confirm with your accountant.

Only the signed Stripe webhook can mark a customer as paid. Renewals, failed cards and cancellations update the portal automatically, and you get an alert email for each.

Test mode

  1. Stripe → toggle Test mode → create the same 6 prices and a test webhook → paste the test keys and IDs in /super → Settings.
  2. Pay with card 4242 4242 4242 4242, any future date, any CVC.
  3. Switch back to the live keys and IDs afterwards.

Wave (invoices)

  1. Wave → create one product per plan (Sales → Products) and an API token (needs a Wave plan with API access).
  2. Paste token, business ID and product IDs in /super → Settings → Wave.
  3. When a customer clicks "Choose plan" without card payment, you get an email; send the invoice and set the portal to active in /super → Subscribers. Paid status syncs hourly.

Where to see money

/super → Payments (history, monthly recurring revenue) and the Monday scorecard.
