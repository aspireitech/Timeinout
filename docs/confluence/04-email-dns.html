All email goes out through Microsoft 365 using Microsoft Graph, from two mailboxes.

MailboxSends
contact@clockinoutapp.comSign-in codes, welcome emails, trial emails, outreach to leads, alerts to you, scorecard. Replies from leads arrive here.
reports@clockinoutapp.comCustomer attendance reports (replies go to contact@)

How it is connected (one-time setup, already done)

  1. Microsoft Entra admin center → App registrations → New registration (single tenant).
  2. API permissions → Microsoft Graph → Application permission Mail.Send → Grant admin consent.
  3. Certificates & secrets → New client secret → copy the Value once.
  4. Put tenant ID, client ID and client secret in app/config.php under graph, with 'mail' => ['driver' => 'graph'].
  5. Recommended: restrict the app to the two mailboxes with an Exchange ApplicationAccessPolicy.

The client secret expires (6, 12 or 24 months). Put the expiry date in your calendar. When it expires all email stops: create a new secret in Entra → update config.php → test.

Test email

  1. /super → Settings → bottom of the page → Send a test email → choose contact or reports → Send.
  2. Check the inbox (and spam).

Check any time at mxtoolbox.com (SPF, DKIM with selector1, DMARC). Status: configured and working (copies land in the inbox).

Who gets alerts

All provider alerts go to contact@ plus every address in /super → Settings → Alerts to you → "Also send alerts to" (up to 5).
