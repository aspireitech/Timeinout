Your control room at clockinoutapp.com/super. Every customer, lead, prospect, payment and setting is here.

Sign in (3 ways, in order)

  1. Sign in with Google (recommended): your Google account with 2-Step Verification.
  2. Email me a sign-in code: if Google is down, a 6-digit code goes to the provider email.
  3. Break-glass: if Google and email are both down: break-glass password plus one unused recovery code.
  4. Last resort (server access): over SSH run php cron/super_password.php --recovery in the site folder, then create new recovery codes.

Set up or change sign-in: /super → Sign-in

  1. Google keys: Google Cloud console → APIs & Services → Credentials → OAuth client (Web application) with redirect URIs https://clockinoutapp.com/super/google/callback and https://www.clockinoutapp.com/super/google/callback → paste Client ID and secret → Save Google keys.
  2. Break-glass password: 14+ characters → Save. Store it in your password manager.
  3. Recovery codes: Create → 10 codes appear once → copy all into your password manager. Each works once.

Subscribers (customers)

  • Each row: portal link, owner email, people, activity, billing state, where they came from ("via facebook", "via outreach"), and "subdomain not live yet" if its own address still needs creating.
  • Change plan or status (trial / active / suspended / cancelled) → Save.
  • Reset owner password → a temporary password is shown once; the owner must change it at first sign-in.
  • Delete portal → kept 30 days, restorable under Deleted; after 30 days the hourly job removes it (a copy goes to backups/deleted/).
  • Reset demo portal rebuilds the public demo with fresh sample data.

New portal (for a customer you set up yourself)

  1. Optional own database: hPanel → Databases → create a new empty database and user first.
  2. /super → New portal → business name, address, industry, time zone, owner name and email, plan, trial or active → database: shared or own (enter the database details) → Create.
  3. The owner's first password is shown once; send it to them securely.

Leads (demo requests)

Every "Book a demo" form lands here and in your email. Set status (New → Contacted → Qualified → Won / Lost), add notes, export CSV.

Prospects (automatic outreach)

See page 8 for the full outreach process. Your daily job here: when someone replies, set them to Replied; when an email bounces, set Bounced.

Settings

Email delivery and test email, admin sign-in codes, Stripe keys and price IDs, Stripe Tax, Wave, Search Console and Google Analytics, trial follow-up on/off and promotion line, and Alerts to you (extra alert addresses).

Payments, Requests, Audit log

  • Payments: every payment, MRR, record a cheque or bank transfer by hand.
  • Requests: feature requests from customers.
  • Audit log: every sign-in and change across all portals, filter and export.
